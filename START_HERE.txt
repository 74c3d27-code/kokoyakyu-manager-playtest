1. docs/BEGINNER_GUIDE.html

ローカル起動
1. Node.js 22をインストール
2. Windowsは START_LOCAL_WINDOWS.bat をダブルクリック
3. macOS/Linuxはターミナルで ./start-local.sh
4. ブラウザで http://localhost:4173

手動で実行する場合
npm install
npm test
npm run dev

Cloudflare Pages設定
Production branch: main
Framework preset: None
Build command: npm run build
Build output directory: dist
